# 할일 알람 (ActionAlarm)

정해 둔 시각에 알람이 울리고, 알람을 끄면 **화면 오른쪽 위에 "이 행동을 하셨나요?" 작은 확인창이 계속 떠 있는** 안드로이드 앱입니다. 확인창의 **[완료했어요]**를 누르면 창이 사라집니다.

## 동작 방식

1. 알람 추가: 시각 + 알람 이유(예: 약 먹을 시간) + 해야 할 행동(예: 혈압약 1알 복용)
2. 시각이 되면 잠금화면 위로 알람 화면이 뜨고 소리·진동이 울림
3. **[알람 끄기]** → 소리가 멈추고 큰 화면은 닫히며, **오른쪽 위에 작은 확인창**이 뜸
4. 확인창은 다른 앱을 쓰는 동안에도 계속 떠 있음 (다시 알람이 울리지는 않음)
5. **[✔ 완료했어요]**를 누르면 확인창이 사라짐
6. 여러 알람이 밀려 있으면 확인창이 세로로 쌓이고, 제목 줄을 끌어서 창 위치를 옮길 수 있음
7. 아무도 끄지 않으면 3분 뒤 자동으로 소리가 멈추고 확인창으로 전환
8. 확인창이 안 보이는 잠금화면에서는 알림창의 "✔ 완료했어요" 버튼이나 앱 목록의 "✔ 완료" 버튼으로도 완료 가능
9. 재부팅 후에도 완료 안 한 확인창과 알람 예약이 복구됨

목록에서 항목을 누르면 수정, 길게 누르면 삭제, 스위치로 켜고 끕니다.

## 빌드 방법

1. [Android Studio](https://developer.android.com/studio) 설치
2. `File > Open` 으로 이 `ActionAlarm` 폴더 열기 (Gradle 동기화가 자동으로 진행됨)
3. 휴대폰을 USB로 연결(개발자 옵션 → USB 디버깅 켜기) 후 ▶ Run
   - 또는 `Build > Build App Bundle(s) / APK(s) > Build APK(s)` 로 APK 생성 → 휴대폰에 옮겨 설치

## 처음 실행 시 권한

앱 상단에 주황색 안내가 뜨면 눌러서 차례로 허용해 주세요.
- 알림 권한 (Android 13+)
- 알람 및 리마인더 권한 (Android 12)
- **다른 앱 위에 표시** — 오른쪽 위 작은 확인창에 꼭 필요
- 전체 화면 알림 권한 (Android 14+, 잠금화면에 알람 화면 표시용)

'다른 앱 위에 표시'를 허용하지 않으면 작은 확인창 대신 알림창에 확인 알림이 남습니다.

삼성·샤오미 등 일부 기기는 배터리 절약 기능이 앱을 막을 수 있으니, 설정 → 애플리케이션 → 할일 알람 → 배터리 → **제한 없음**으로 두는 것을 권장합니다.

## 설정값 바꾸기

| 항목 | 위치 |
|---|---|
| 자동 소리 멈춤 (기본 3분) | `AlarmService.kt` 의 `RING_DURATION_MS` |
| 확인창 크기·모양 | `res/layout/overlay_card.xml` |
| 확인창 처음 위치 | `PendingOverlay.kt` 의 `posX`, `posY` |

요구사항: Android 8.1(API 27) 이상. 외부 라이브러리 없이 안드로이드 기본 API만 사용합니다.
